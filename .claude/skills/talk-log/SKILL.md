# Talk Log Skill

## 목적
대화에서 고민한 내용, 의사결정 과정, 배움을 `docs/logs/{n}-weeks-talk-log.md`에 기록한다.

## 저장 형식

각 항목은 다음 구조를 따른다:

```markdown
## {날짜}: {고민 주제 한 줄 요약}

### 고민한 부분
- 어떤 상황에서 어떤 의문이 생겼는지

### 선택지
1. **선택지 A** — 설명
2. **선택지 B** — 설명

### 선택한 답
- N번 선택
- 이유: ...

### 느낀 점
- 개발자가 이 경험에서 느꼈을 내용
```

## 규칙

1. **기존 파일에 이어쓴다.** 기존 내용을 절대 삭제하지 않는다.
2. **대화 맥락에서 추출한다.** 대화에서 고민한 부분, Claude가 제시한 선택지, 사용자가 고른 답을 기반으로 작성한다.
3. **느낀 점은 추론한다.** 사용자의 선택과 맥락을 바탕으로 개발자가 느꼈을 법한 내용을 작성한다.
4. **선택지가 없는 경우** 의사결정이 아닌 학습/탐색인 경우 `### 선택지`, `### 선택한 답` 섹션을 생략하고 `### 내용 정리`로 대체할 수 있다.
5. **날짜는 currentDate를 사용한다.**
6. **주차 파일이 비어있으면** 최상단에 `# {n}주차 대화 로그` 헤더를 추가한다.
7. **항목 사이에 `---` 구분선을 넣는다.**
